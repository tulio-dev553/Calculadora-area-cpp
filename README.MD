Funcionalidades

O programa permite calcular:
✔️ Área de um triângulo
✔️ Área de um trapézio
O usuário escolhe a opção no menu e insere os valores necessários.

🧠 Conceitos praticados

Variáveis
Entrada de dados com cin
Saída de dados com cout
Estruturas condicionais (if, else)
Menu de opções
Operações matemáticas
                         
💻 Código principal
                         
O programa:
                         
Mostra um menu de opções
Recebe os valores digitados pelo usuário
Valida se os números são maiores que zero
Calcula e mostra a área correta
